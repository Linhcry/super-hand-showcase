# 数据与评估

## 数据角色

| 数据 | 产生方式 | 用途 | 公开形式 |
|---|---|---|---|
| 合成RGB-D | MuJoCo渲染RGB、深度、几何ID | 8类分割、场景随机化 | 方法与配置摘要 |
| 分阶段仿真轨迹 | 任务执行保存状态和控制 | 经验初始化、合成图姿态、时间学习 | 数量、维数和状态摘要 |
| 墨迹足迹 | 解析合成与可选历史接触 | 覆盖训练、阈值标定、独立测试 | 生成规模与划分说明 |
| 实拍增量标签 | RGB-D采集与人工标签 | 相机与场景域适配 | 接口和数据角色说明 |
| 实际示教及手反馈 | 现场真实关节、工具和手部反馈 | 固定布局与部署核对 | 方法说明 |
| 对照场景 | 固定题目、布局、种子和范围 | 候选比较与可靠性复核 | 统计与评估规则 |

原始图像、状态数组、控制轨迹、示教与设备标定均不在公开仓库中。

## 随机化与数据划分

合成数据可按完整轨迹的阶段姿态采样，改变对象位置、平面转角、光照、桌面颜色、相机高度和像素噪声，保留遮挡与物体重叠。生成记录包含种子、数量与姿态来源。

合成训练/验证采用固定划分；实拍验证帧有独立角色。墨迹的训练、标定与测试使用不同种子。IK初值训练按目标来源分组留出，减少同一目标经验同时出现在两侧。

## 独立评估

完整任务评估分开记录以下维度：

1. 动作流程是否完成，工具是否按阶段取放。
2. 机械与几何检查是否通过。
3. 墨迹是否覆盖目标，首次落墨和修补负担分别是什么。
4. 目标精度是否满足对应定义。
5. 从开始到结束的耗时与预留预算。
6. 运行目标是否来自实际视觉或已明示的应用路线。

控制器运行日志与独立审计结果有不同职责。保存状态的机械审计也不能自动作为连续时间或真实硬件的碰撞证明。

## 固定对照与失败分母

同一候选的对照保持任务范围、题目、场景、种子和指标定义。批次同时记录成功、失败和未执行；单个成功视频不代替原组结果。

V147原30初赛场景14通过、16未通过，全部失败保留在分母内。部分候选训练失败、完整任务失败或没有实质收益时，保留原基底和诊断记录。

## 结果的可追溯性

内部任务记录配置、源码/权重摘要、数据来源、随机种子、训练与验证指标、完整报告、失败原因、轨迹和资源用量。本公开展示只发布精简摘要和媒体SHA256，不包含原始输入、设备身份或个人机器路径。
